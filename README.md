# 🍷 Catesivins

**Aplicació mòbil per a descobrir, registrar i organitzar experiències de tast de vins.**

Catesivins és un projecte de desenvolupament d'una aplicació Android creat com a projecte final del cicle formatiu de grau superior de Desenvolupament d'Aplicacions Multiplataforma (DAM).

L'objectiu és oferir un espai digital on centralitzar la informació relacionada amb el tast de vins, amb una interfície intuïtiva i una arquitectura preparada per a treballar amb serveis al núvol.

---

## 📱 Sobre el projecte

Catesivins naix de la idea de combinar tecnologia i cultura vinícola mitjançant una aplicació mòbil nativa per a Android.

El projecte permet posar en pràctica coneixements de desenvolupament d'aplicacions, disseny d'interfícies, gestió de dades i integració amb serveis de backend.

### Objectius principals

- Desenvolupar una aplicació nativa per a Android.
- Crear una interfície d'usuari moderna i intuïtiva.
- Organitzar el codi seguint una estructura clara i mantenible.
- Integrar serveis de Firebase.
- Aplicar els coneixements adquirits durant el cicle formatiu de DAM.

## ✨ Funcionalitats

Aquest apartat recull les funcionalitats principals de l'aplicació.

- **Interfície Android:** experiència d'usuari adaptada a dispositius mòbils.
- **Navegació entre pantalles:** organització de les diferents seccions de l'aplicació.
- **Integració amb Firebase:** connexió amb serveis de backend.
- **Gestió de la informació:** estructura orientada a treballar amb dades relacionades amb el món del vi.

> Les funcionalitats concretes i el seu estat de desenvolupament es poden ampliar a mesura que evolucione el projecte.

## 🏗️ Arquitectura i desenvolupament

El projecte s'ha desenvolupat amb Kotlin i Jetpack Compose, aprofitant el model declaratiu per a construir la interfície d'usuari.

L'organització del codi busca separar les diferents responsabilitats de l'aplicació per facilitar-ne la lectura, el manteniment i les ampliacions futures.

La integració amb Firebase permet incorporar serveis de backend sense haver de construir tota la infraestructura del servidor des de zero.

## 🚀 Instal·lació i execució

Per a obrir i executar el projecte en un entorn local:

1. Instal·la [Android Studio](https://developer.android.com/studio).
2. Clona aquest repositori:

   ```bash
   git clone URL_DEL_REPOSITORI
   ```

3. Obri el projecte des d'Android Studio.
4. Espera que Gradle sincronitze les dependències.
5. Configura els serveis de Firebase necessaris per al projecte.
6. Executa l'aplicació en un emulador Android o en un dispositiu físic compatible.

**Nota:** cal substituir `URL_DEL_REPOSITORI` per l'adreça real del repositori. La configuració de Firebase i les versions requerides dependran dels fitxers del projecte.
